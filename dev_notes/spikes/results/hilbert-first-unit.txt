=== 1. the capability a provider can state, and the one it can prove ===
  matrix-free leaf, properties = c('hermitian'):
    value  : TRUE
    source : user_declaration
    guarantee: identity
  the same operator as a dense leaf, with no properties given:
    value  : TRUE
    source : computation
    guarantee: identity

  So the route that materialises the operator gets the better evidence, and
  the matrix-free route -- the one the layer exists for -- gets a bare
  declaration. normalise_properties() stamps ev_declared() unconditionally;
  ev_construction() is internal and there is no properties= form reaching it.

  verify(H) on the matrix-free leaf: pass
    checks: adjoint consistency, view identities, real transpose equals adjoint, linearity, block consistency, shape and dtype, complex linearity, declared capabilities, purity, gemm agreement, materialisation agreement

=== 5. refusal at V = 0: the isolation condition and the refusal are one ===
     n    q (top Ritz)      q - a         issue?  eigs nconv  eigs cert
    10   1.979642883762   -2.035712e-02   FALSE   1 of 1      qualified
    40   1.998532362102   -1.467638e-03   FALSE   1 of 1      qualified
   100   1.999602918148   -3.970819e-04   FALSE   0 of 1      fail
  Every top Ritz value sits strictly inside (-2, 2): these are discretisations
  of continuous spectrum and H_free has no eigenvalues at all. q - a > 0 fails
  on its own terms, so nothing separate has to detect the case.

  The eigensolver is a second signal and not a substitute for the first. Where
  it converges, the value it returns is still inside the band and the layer
  still has to refuse; where it stalls, the stall is about the clustering near
  the band edge rather than about the absence of an eigenvalue. Only q - a > 0
  distinguishes 'no eigenvalue here' from 'a hard eigenvalue here'.
