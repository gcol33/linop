# S0.6 -- finite-section bound feasibility

Run 2026-07-27. Script `dev_notes/spikes/S0.6_finite_section.R`, all numbers below
reproduced by it. Plan section 9 asks: derive the closed-form decay rate, the truncation
bound and the isolation gap, and check each is computable from quantities the
discretisation object will hold. "If any is not, section 8.10 needs a different first
class, and better to learn that now than in Phase 5."

## Verdict: feasible. Section 8.10's first rigorous class stands.

All three quantities are closed-form and computable, and one of them needs only two
numbers from the computed eigenvector. One correction is required: the certificate needs
an arithmetic floor term, without which `verify()` reports failure on fully converged
results.

---

## Setting

```
(H u)_j = u_{j-1} + u_{j+1} + V_j u_j          on ell^2(Z)
```

`V` real with support in `[-R, R]`. `V` finitely supported implies `V` compact, so by
Weyl's theorem `sigma_ess(H) = sigma_ess(H_free)`, and `H_free` is the Laurent operator
with symbol `2 cos(theta)`, giving

```
sigma_ess(H) = [-2, 2]
```

The band edge `a = 2` is therefore known a priori from the limiting coefficients, not
estimated. This is what makes the whole scheme work and is the reason this class was
chosen over general banded Toeplitz.

## (a) Decay rate: closed form in `lambda` alone

For `|j| > R` the eigenvalue equation is the free recurrence

```
u_{j-1} + u_{j+1} = lambda u_j
```

Substituting `u_j = z^j` gives the characteristic equation `z^2 - lambda z + 1 = 0`, with
roots `z_+- = (lambda +- sqrt(lambda^2 - 4))/2` satisfying `z_+ z_- = 1`. For
`|lambda| > 2` both roots are real and reciprocal, so exactly one lies in the open unit
disc. Writing `|lambda| = 2 cosh(alpha)` gives `z = e^{+-alpha}`, hence

```
alpha(lambda) = arccosh(|lambda| / 2)
rho(lambda)   = e^{-alpha} = |lambda|/2 - sqrt((lambda/2)^2 - 1)      in (0, 1)
```

Membership in `ell^2` forces the decaying branch on each side, so for `j >= R` the
eigenfunction is **exactly** `A rho^j`, and for `j <= -R` exactly `B rho^{|j|}`. Not
asymptotically -- exactly, because the recurrence holds exactly outside the support. This
is the property that makes the truncation error a closed form rather than an existence
statement, and it is precisely why the plan restricts the first release to finite support.

**Verified.** With `V = v delta_0` the model has the exact solution
`lambda = sign(v) sqrt(v^2 + 4)`, `rho = (-|v| + sqrt(v^2+4))/2`. For `v = 1`,
`lambda = sqrt(5)` and `rho = (sqrt(5)-1)/2 = 0.618033988750`, the golden-ratio conjugate.
Measured ratios `u_{j+1}/u_j` for `j = 1..20` agree with `rho(lambda_n)` to
**3.3e-15**. The closed form `rho_of(lambda)` reproduces `rho_exact` under `all.equal` for
`v = 0.5, 1, 2, 4`.

## (b) Truncation bound: two entries of the computed eigenvector

Let `H_n = P_n H P_n` on indices `|j| <= n` with `n > R`, let `(lambda_n, u)` be an
eigenpair of `H_n`, and let `u~` be `u` extended by zero to `ell^2(Z)`.

Then `(H - lambda_n) u~` vanishes at every `|j| <= n`, because the couplings `P_n` removed
multiply entries of `u~` that are zero; and it vanishes at `|j| > n+1`, where every term is
zero. It is nonzero **only at the two sites** `j = +-(n+1)`:

```
r_{n+1} = u_n ,    r_{-(n+1)} = u_{-n}
```

`H` is self-adjoint, so the standard residual bound gives

```
dist(lambda_n, sigma(H))  <=  ||r|| / ||u~||  =  sqrt(u_n^2 + u_{-n}^2) / ||u||  =:  eta
```

**No unknown constants, no norm estimates, and only the first and last entries of the
computed eigenvector are needed.**

A priori, `u_n ~ A rho^n`, so `eta = O(rho^n)`. Verified: `eta / rho^n` is constant in `n`
to four digits (0.2719 at `v=0.5`, 0.5845 at `v=1`, 0.9852 at `v=2`, 1.2629 at `v=4`),
confirming the rate is exactly `rho` with a computable constant.

Measured, `v = 1`:

| n | lambda_n | true error | eta | error <= eta |
|---|---|---|---|---|
| 5 | 2.233209543058 | 2.86e-03 | 5.41e-02 | yes |
| 10 | 2.236045382463 | 2.26e-05 | 4.75e-03 | yes |
| 20 | 2.236067976007 | 1.49e-09 | 3.86e-05 | yes |
| 40 | 2.236067977500 | 8.88e-16 | 2.55e-09 | yes |
| 80 | 2.236067977500 | 2.22e-15 | 1.12e-17 | **no** |

## The correction: the bound needs an arithmetic floor

The last row is not a failure of the mathematics. At `n = 80` the analytic residual has
decayed to `1.1e-17`, below machine epsilon, while the observed "error" `2.2e-15` is
roundoff in the finite eigensolve, not truncation. The same pattern appears at `v = 2`
(`n >= 40`) and `v = 4` (`n >= 40`), and in the three-site test at `n >= 40`. In every such
row the true error is at the `1e-15` level and constant, i.e. the answer is fully
converged.

The bound as stated is an exact-arithmetic statement. The certified quantity must be

```
dist(lambda_n, sigma(H))  <=  eta  +  c * ||H|| * eps
```

with `||H|| <= 2 + max|V|` available in closed form for this class and `eps` the machine
epsilon. With `||H|| ~ 4` to `6` this floor is `~1e-15`, which matches the observed plateau.

**This is a Phase 5 requirement and a Phase 2 one.** Plan section 6's certificate table has
no roundoff term anywhere. Without it, `verify(fit, A)` returns `fail` on exactly the
results that are most converged, which is the worst possible failure mode for a package
whose selling point is honest certification. The `residual` and `backward error` lines both
need it.

## (c) Isolation gap: Kato-Temple against a known band edge

Because `a = 2` is known exactly, Kato-Temple applies without estimating anything. With
`q = <u, H u> / <u, u>` the Rayleigh quotient, `eta` as above, and no spectrum in `(a, q)`:

```
q - eta^2 / (b - q)   <=   lambda   <=   q + eta^2 / (q - a)
```

The quadratic improvement is large. Measured, `v = 1`:

| n | eta (linear bound) | Kato-Temple half-width | contains truth |
|---|---|---|---|
| 5 | 5.41e-02 | 1.25e-02 | yes |
| 10 | 4.75e-03 | 9.58e-05 | yes |
| 20 | 3.86e-05 | 6.32e-09 | yes |
| 40 | 2.55e-09 | 2.76e-17 | yes |

Four orders of magnitude at `n = 20`. The bracket contains the exact `sqrt(5)` in every
case.

The `q - a > 0` requirement is exactly the isolation condition: it fails precisely when the
Ritz value has not separated from the essential spectrum, which is the case where a
certificate should not be issued. The gap bound and the refusal criterion are the same
inequality, which is a good sign for the design.

## (d) The refusal case behaves as section 8.9 requires

With `V = 0`:

| n | dimension | spectrum range | any \|lambda\| > 2 |
|---|---|---|---|
| 10 | 21 | [-1.979642884, 1.979642884] | no |
| 40 | 81 | [-1.998532362, 1.998532362] | no |
| 100 | 201 | [-1.999758127, 1.999758127] | no |

Every finite-section eigenvalue lies strictly inside `(-2, 2)` and approaches the edge from
below as `n` grows. These are discretisations of continuous spectrum; `H_free` has no
eigenvalues at all. `eigs()` must refuse and `spectral_approximation()` must return
something not called an eigenvalue, exactly as section 8.9 and the flagship in 8.10
specify. Note also that `q - a > 0` fails for all of them, so the Kato-Temple route refuses
on its own terms.

The bound needs no closed-form eigenvalue, only the computed vector, so it extends to any

## What the discretisation object must carry

| Quantity | Source |
|---|---|
| `rho(lambda)`, `alpha(lambda)` | `lambda` alone, closed form |
| `eta` | entries `u_{-n}`, `u_n` of the computed eigenvector, and `\|\|u\|\|` |
| Kato-Temple bracket | `eta`, Rayleigh quotient `q`, band edge `a` |
| band edge `a = 2` | limiting coefficients (off-diagonal 1, diagonal 0) via Weyl |
| arithmetic floor | `\|\|H\|\| <= 2 + max\|V\|` and `.Machine$double.eps` |
| support radius `R` | only to assert `n > R`, so the tail is free |

All of these are either constants of the operator class or read off the finite result. No
quantity requires an estimate, a probe or a user declaration. **Feasibility confirmed.**
